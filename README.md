# 本地证件照工具箱（微信小程序）

一个**纯本地**处理的证件照制作小程序：换底色、规格裁剪、A4 打印排版。照片**只在你自己的手机里处理，绝不上传**。

## 功能

- ✅ **换底色**：点选照片背景 → 一键换成白/蓝/红/自定义色，容差可调
- ✅ **规格裁剪**：一寸、二寸、护照、签证等标准尺寸居中裁剪
- ✅ **A4 排版**：一键排成 A4 打印样式，可多张同版（激励视频解锁高清）
- ✅ 保存到相册、本地使用记录

## 隐私承诺（上架核心卖点）

- **零上传**：无后端、无云开发、无任何网络请求
- **不留痕**：处理过程只使用临时目录，关闭即清理
- 唯一本地存储是「使用记录」元数据（时间/规格），**不含你的照片**

## 快速开始（开发者工具）

1. **导入项目**：用微信开发者工具「导入项目」，选择本 `F:\证件照工具` 目录
2. **填写 AppID**：`project.config.json` 中的 `appid` 目前是 `touristappid`（游客模式）。
   首次真机测试需要改为你的小程序 AppID：
   - 前往 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册/登录小程序账号
   - 在「开发-开发管理-开发设置」复制 AppID
   - 粘贴到 `project.config.json` 的 `appid`（或直接用开发者工具图形界面改）
3. **编译运行**：点击「编译」，在模拟器即可体验完整流程
4. **真机预览**：点「预览」扫码，真机上测试相册保存、点选取色

## 上架需要准备（提交审核前）

### 一、备案（强制，2023年9月起所有小程序必须）
- 小程序备案流程：平台初审 → **工信部短信核验（24小时内，务必及时点）** → 通管局审核
- 全程约 5-20 个工作日，提前申请

### 二、类目（个人主体）
- 在「设置-基本设置-服务类目」选择**工具 > 图片/视频处理** 或其他可用工具类目
- 个人主体可做的原则：**非盈利、低风险、工具化**
- 本项目纯工具、零上传，符合个人主体可上架范围

### 三、隐私协议（必备）
- 微信要求小程序有隐私协议弹窗
- 可在「设置-服务内容声明」填写，声明：**所有图片在本地处理，不上传服务器，不存储到云端**

### 四、AppID / 名称
- 名称建议：`XX证件照`（好记、明确用途）
- 需要 AppID 才能提交审核

## 开启广告变现（激励视频）

变现方式：用户观看激励视频解锁「高清导出 / A4 排版」。纯本地 MVP 阶段为占位。

步骤：
1. 在微信公众平台开通「流量主」（小程序累计独立访客达到 1000 UV 后开放）
2. 创建**激励视频广告位**，获得 `adUnitId`
3. 填入 `miniprogram/utils/ad.js` 的 `REWARD_VIDEO_AD_UNIT_ID`

> `watchAd()` 已做兼容：`adUnitId` 为空时自动放行，方便开发调试，不影响功能。

## 已知限制（诚实说明）

- **换底色是"改纯色背景"**，对人物边缘不做 AI 抠图。纯色背景（墙/幕布/天空）效果最佳；复杂背景/发丝边缘会保留原色。这是"不用 AI、零上传"换取合规与隐私的取舍。
- 激励视频为本地占位，无严格防刷，MVP 阶段可接受。
- 无云同步，换手机数据不迁移。
