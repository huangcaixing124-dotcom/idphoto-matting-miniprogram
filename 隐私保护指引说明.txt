 小程序「用户隐私保护指引」填写说明
 （证件照工具 · 版本 v1.0.0）
================================================================

------------------------------------------------------------------------
一、需声明的隐私相关能力（勾选项）
------------------------------------------------------------------------

在「用户隐私保护指引」页面，请按下表勾选"本小程序用到哪
些处理信息的能力"。原则：只勾真实用到的，一个都不要多。

  ┌──────────────────────┬────────┬───────────────────────────────┐
  │ 后台列出的能力        │ 是否勾选 │ 备注                        │
  ├──────────────────────┼────────┼───────────────────────────────┤
  │ 相册（读取图片）      │   ✔ 勾  │ 用户选择照片制作证件照       │
  │ 相册（写入/保存图片） │   ✔ 勾  │ 保存制作完成的证件照到相册   │
  │ 网络访问             │   ✔ 勾  │ 上传照片抠图、接收处理结果   │
  │ 摄像头 / 拍摄        │   ✘ 不勾 │ 已限制仅从相册选图，不拍摄    │
  │ 麦克风 / 录音        │   ✘ 不勾 │ 未使用                      │
  │ 位置信息             │   ✘ 不勾 │ 未使用                      │
  │ 手机号               │   ✘ 不勾 │ 未使用、无需登录             │
  │ 身份证号 / 真实姓名  │   ✘ 不勾 │ 不收集任何身份信息（重点）    │
  │ 微信昵称 / 头像      │   ✘ 不勾 │ 未读取                      │
  │ 蓝牙 / WiFi / 运动等 │   ✘ 不勾 │ 均未使用                    │
  └──────────────────────┴────────┴───────────────────────────────┘

  ★ 特别提醒：本小程序为"证件照"制作工具，但处理的是用户自行
    选中的普通照片，并非身份证件信息。因此【身份证号 / 真实姓名】
    这一项一定不能勾选，否则会构成"过度收集个人信息"，审核必被打回。


------------------------------------------------------------------------
二、各项"用于什么功能"填写（逐项粘贴）
------------------------------------------------------------------------

若后台要求为每一项能力填写具体功能用途，请按下表填写：

  · 相册（读取）→  选择照片制作证件照
  · 相册（写入）→  将制作完成的证件照保存到用户相册
  · 网络访问     →  将用户选中的照片上传至服务器进行抠图处理，
                    并接收处理结果


------------------------------------------------------------------------
三、整体的个人信息保护说明（页面底部大段文案，可直接粘贴）
------------------------------------------------------------------------

  本小程序用于制作标准证件照，核心流程为"选择照片 →
  抠图/换底色 → 保存到相册"。

  使用过程中，用户自行选中的照片会经加密方式（HTTPS）上传至
  自建服务器进行抠图处理；处理结果会在服务器暂存，以便相同的
  处理请求可直接复用，并定期自动清理，不用于任何其他用途。

  本小程序不收集任何用户身份识别信息（不含真实姓名、身份证号、
  手机号、位置等），也无需登录。

  本小程序所声明的全部权限（读取相册、保存到相册、网络访问）
  仅用于完成上述核心功能。


------------------------------------------------------------------------
四、填写注意事项（红线，务必遵守）
------------------------------------------------------------------------

  1. 只勾选真实使用到的能力：勾得越多，审核去核实的点越多；
     勾了未使用的能力会被判定"声明了却未用于对应功能"而打回。

  2. 身份证号、手机号、位置等一律不勾选、不提及。

  3. 说明文字中的口径，须与小程序的隐私弹窗、实际后端行为保持
     一致——目前统一为"暂存去重 + 定期自动清理、不用于其他用途"。
     不要改回"立即删除、不留存"，也不要写成"会长期保存用户数据"。

  4. 若开启"允许用户撤回同意"等能力，请一并核对代码中的隐私
     授权提示，确保与文案一致。
